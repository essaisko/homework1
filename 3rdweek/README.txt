# 🎮 Dart RPG 게임

이 프로그램은 Dart로 제작된 간단한 텍스트 기반 RPG 게임입니다. 플레이어는 캐릭터를 생성하여 다양한 몬스터와 전투를 진행하며 게임을 즐길 수 있습니다.

## 🚀 게임 기능

### 1. 캐릭터 생성
- 게임 시작 시 플레이어는 한글 또는 영문으로 이름을 입력할 수 있습니다.
- 캐릭터의 체력, 공격력, 방어력은 `characters.txt` 파일에서 가져옵니다.

### 🎯 캐릭터 보너스 체력
- 게임 시작 시 30% 확률로 캐릭터의 체력을 10 증가시킵니다.

### 🧙 전투 시스템
- 캐릭터는 몬스터를 공격하거나 방어할 수 있으며, 특별한 아이템을 사용할 수 있습니다.
- 아이템 사용 시 한 번만 공격력이 두 배로 증가하며, 한 전투에서 한 번만 사용 가능합니다.
- 이미 아이템을 사용했다면 다시 행동을 선택하도록 안내합니다.

### 🛡️ 몬스터 방어력 증가
- 몬스터는 전투 중 매 3번째 턴마다 방어력이 2씩 증가하여 더 강력한 방어력을 갖게 됩니다.

### 📖 몬스터 정보
- 몬스터의 정보는 `monsters.txt` 파일에서 이름, 체력, 공격력을 읽어와 설정됩니다.

### 💾 게임 결과 저장
- 게임 종료 후 결과(승리 또는 패배 여부, 캐릭터의 남은 체력)를 `result.txt` 파일에 저장할 수 있습니다.

## 📌 사용법

### 실행 방법

터미널에서 다음 명령어를 입력하여 실행하세요:

```bash
dart run 파일명.dart
```

### 입력 규칙
- 캐릭터 이름은 한글 또는 영문만 입력 가능합니다.
- 행동 선택 시 다음 번호를 입력하세요:
  - `1`: 공격
  - `2`: 방어
  - `3`: 아이템 사용
  - 방어 시 피해는 없습니다.
- 아이템 사용: 전투 중 1번만 사용 가능하며, 사용 후 공격력이 두 배가 됩니다.

## 📂 필요한 파일

게임 실행 전에 다음 두 파일이 필요합니다:

### `characters.txt`

캐릭터의 초기 스탯을 저장합니다. 형식:

```
체력,공격력,방어력
예시: 100,20,5
```

### `monsters.txt`

몬스터의 정보를 저장합니다. 형식:

```
몬스터이름,체력,공격력
예시:
슬라임,50,10
고블린,30,15
```

## 📝 게임 결과 저장
게임을 마친 후 결과를 저장할지 물어보며, 저장하면 결과는 `result.txt` 파일로 생성됩니다.
