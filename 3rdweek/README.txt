# RPG Battle Game (Dart)

## 📌 개요
이 프로젝트는 Dart 언어를 사용하여 만든 간단한 텍스트 기반 RPG 전투 게임입니다. 
사용자는 몬스터와의 턴제 전투를 진행하며, 몬스터를 모두 물리치면 승리합니다.

## 🎮 게임 실행 방법
1. **Dart 설치**
   - Dart가 설치되어 있지 않다면 [Dart 공식 사이트](https://dart.dev/get-dart)에서 설치하세요.

2. **프로젝트 실행**
   ```sh
   dart main.dart
   ```

3. **게임 진행**
   - 캐릭터의 이름을 입력합니다.
   - 랜덤으로 등장하는 몬스터와 전투를 진행합니다.
   - 공격(1) 또는 방어(2)를 선택하여 턴을 진행합니다.
   - 모든 몬스터를 처치하면 게임에서 승리합니다.
   - 게임 종료 후 결과를 저장할 수 있습니다.

## 📜 파일 설명
- **`main.dart`**: 게임의 전체 로직을 구현한 메인 코드 파일
- **`characters.txt`**: 캐릭터의 초기 능력치 (체력, 공격력, 방어력) 저장
- **`monsters.txt`**: 몬스터 리스트 (이름, 체력, 공격력 범위) 저장
- **`result.txt`**: 게임 종료 후 저장된 결과 파일

## 🕹️ 게임 진행 방식
1. **캐릭터 생성**: 사용자가 캐릭터의 이름을 입력합니다.
2. **전투 시작**: 랜덤으로 몬스터가 등장합니다.
3. **턴제 전투**:
   - 플레이어는 공격(1) 또는 방어(2)를 선택합니다.
   - 몬스터는 자동으로 공격합니다.
   - 전투가 끝나면 다음 몬스터와의 전투 여부를 선택합니다.
4. **게임 종료**:
   - 모든 몬스터를 물리치면 축하 메시지가 출력됩니다.
   - 패배하면 게임이 종료됩니다.
   - 결과를 파일에 저장할 수 있습니다.

## 🔧 게임 데이터 설정
- **캐릭터 능력치 변경** (`characters.txt`)
  ```txt
  50,10,5  # 체력 50, 공격력 10, 방어력 5
  ```
- **몬스터 리스트 변경** (`monsters.txt`)
  ```txt
  Batman,30,12
  Spiderman,20,10
  Superman,30,15
  ```
  - 형식: `이름, 체력, 공격력 최대값`
