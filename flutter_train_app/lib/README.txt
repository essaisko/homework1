# 🚄 Flutter 기차 예매 서비스 과제

사용자가 직접 출발역과 도착역을 선택하고, 원하는 좌석을 터치로 선택하여 예매할 수 있는 간단하고 직관적인 모바일 기차 예매 프로젝트입니다.
Flutter 기반으로 개발되었으며, 다크모드 대응과 예매 흐름에 필요한 핵심 기능들을 간결하게 구현했습니다.

---

## ✅ 구현된 기능

필수기능
- 홈페이지 구현
- 스테이션 리스트 페이지 구현
- 시트페이지 구현

도전기능
- 출발역, 도착역 중복 없게 수정
- 다크 테마 구현

나만의 기능
- 역 미선택후 예약버튼 누를시 스낵바 메시지 출력
- 좌석 여러개 예약시 좌석 선택 개수 출력 및 예약시 선택 좌석 리스트 출력
